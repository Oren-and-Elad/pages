AI future vision

You have a plan.

One architecture in three layers, built on what you already own. Each layer does one job and can change without rebuilding the others.

One question, end to end

An executive asks“Why has our flagship store taken such a conversion hit last month?”

  1. The chief of staff splits it by function
  2. Head agents, and the chief of staff directly, pass the access check
  3. Each reads only its own slice of the governed data
  4. The answer is checked, then sent back

Layer 1 · Data

One governed centre. Each agent sees only its slice.

  • Every source lands in one place, on your definitions, so every agent reads the same numbers.
  • Each agent reads only its own slice. It cannot change data here, or see tables it is not given.
  • Every query is visible and traceable, back to the source it came from.

Layer 2 · AI Hub

One standard road in. Never locked in.

  • Agents never reach into systems directly. Every request passes the access check and is logged.
  • Any AI tool, agent or model uses the same road. Claude today; swap it and nothing else changes.
  • Agents act only through approved tools: write to Dayforce, call in stock, mail, contracts search.

Layer 3 · AI + people

Agents do the work. People steer.

  • An always-on chief of staff answers the executives, with its own straight line to the AI Hub.
  • Each function gets its own container: a head agent over the agents that do the work, like Merch's call-in and sales insight agents.
  • People approve and direct. Today's dashboards and Qlik stay; agents sit beside them.

Milestones

Build one function at a time. Each step reuses the last.

  • Rostering tool live for the Retail team
  • Built on Dayforce, sales and traffic data
  • Logins and roles: each person sees only their stores
  • Contracts search tool
  • Retail gets its agent, which writes rosters back to Dayforce
  • Merch joins with its agents from day one: call-in and sales insight
  • The governed data layer, the AI Hub, the access check and mail
  • Chief of staff, always on, for the executives
  • A container for each function, Buying next
  • The lab: your people build and test their own agents
  • Proactive engine: opportunities every morning
  • Chat and Office 365
  • Business Central, SharePoint and Dolfin in the governed layer

Each step reuses what the last one built. The order after Merch is illustrative.
