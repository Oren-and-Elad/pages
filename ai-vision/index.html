Open architecture

Three freedoms — never locked in

Every part can change without rebuilding the rest.

1Swap the modelIt sits on top of the frontier model — Claude today. If token costs rise or a model stops fitting, the model swaps underneath and nothing above changes.
2Plug in any agentIn-house or another provider's, under the same rules.
3Bring in other AIs' workOutputs from other AI tools flow in through the same road.

Governance by architecture

Safe because of how it's built

Not a policy document — the design itself limits what each agent can see.

Each agent
Its own
slice
MotherDuck
  • Shares are read-only by design — an agent on a share cannot write
  • A share exposes only the tables you name — the agent does not see that other tables exist
  • Secure Views filter rows and hide or mask columns
  • Every query the agent writes is visible and traceable
  • Data resident in Sydney (AWS ap-southeast-2)
