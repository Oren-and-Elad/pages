# pages — Cleopatra's quick static pages

Marketing and one-off pages (a card for a prospect, an offer, an event). Plain HTML, no build, no keys, no bot.
Every push to `main` goes live within a minute through Cloudflare Pages' GitHub connection
(project `cleopatra-pages`, https://cleopatra-pages.pages.dev/). One folder per page: `start/` → `/start/`.

Rules: no client names unless a director asked; no prices; no secrets; no scripts that send data anywhere.
Anything that answers visitors on its own (Ask Cleo) lives in cleo2 `app/onepager/`, not here.
